# TerraeRarae — Privacy Policy

Política de Privacidade pública do jogo **TerraeRarae**, hospedada via GitHub Pages.

🔗 **URL pública:** https://edsonlima19.github.io/terraerarae-privacy-policy/

Esta URL é a referência informada à Apple no App Store Connect (campo *Privacy Policy URL* do App Privacy e do TestFlight Test Information).

## Idiomas

A página é bilíngue (Português e Inglês), com detecção automática conforme idioma do navegador e seletor manual no topo.

## Atualizações

Para alterar o conteúdo, edite `index.html` e faça commit. O GitHub Pages republica automaticamente em ~1 minuto. Atualize a data de "Última atualização / Last updated" no topo do documento.
